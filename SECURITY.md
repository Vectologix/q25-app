# Politique de sécurité

Q25 est en développement. Le prototype est réservé aux données fictives de test ;
ne l'utilisez pas pour traiter des documents réels. Aucune version n'est prête
pour un usage en production.

## Signaler une vulnérabilité

Le canal privé de signalement reste à définir. Pour demander un contact
confidentiel, ouvrez une [issue](https://github.com/Vectologix/q25-app/issues)
intitulée « Contact sécurité », sans décrire la vulnérabilité ni joindre de fichier.
Attendez qu'un canal privé soit convenu avant de transmettre les détails.

Ne publiez aucun détail exploitable, secret, document personnel ou base de données
dans une issue publique.
