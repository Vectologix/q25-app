# Identité Q25

Assets de marque Q25 fournis : logos SVG/PNG, icônes, favicons et tokens CSS.
Les fichiers sources graphiques sont conservés sans modification ; leurs
empreintes figurent dans [SHA256SUMS](SHA256SUMS).

- Fond foncé : `assets/logos/q25-wordmark-on-dark.svg`.
- Fond clair : `assets/logos/q25-wordmark-on-light.svg`.
- Icône : `assets/icons/q25-app-icon.svg` ; formats Tauri dans `src-tauri/icons/`.
- Palette : `web/brand-tokens.css`, avec secours typographique système.
- Signature : « Vos documents. Vos données. Votre contrôle. »

Ne pas redessiner, déformer, recolorer ou retaper le logo. Respecter son espace
de protection et vérifier contraste et lisibilité. Les assets ne doivent pas
laisser entendre une affiliation gouvernementale ou une conformité automatique.

Le site q25.ai utilise une copie versionnée et contrôlée par empreintes de ces
mêmes fichiers ; les deux projets doivent pouvoir être construits séparément.
